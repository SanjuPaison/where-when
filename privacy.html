Privacy Policy — lifeprediction.net

This policy covers lifeprediction.net as a whole and every interactive astrology tool or widget hosted on it, including but not limited to the Pluto Phases widget and the When & Where widget. All of these tools process everything server-side to compute a result — none of them run entirely on-device.

1. Birth and Event Information You Enter

Depending on which Tool you use, you may be asked to enter your birth date, birth time, birth place, birth place time zone, gender, an event date, and/or a description of an event, along with a mode or category selection relevant to that Tool. Whatever combination of these a given Tool asks for is sent to a server-side function ("the reading service") that computes your chart and result for that one request. It is used only to produce your result and is not retained beyond what is needed to do so and, where a Tool applies one, to enforce the usage limit described in Section 6.

2. Geocoding Your Birth Place

To convert the birth place you type (e.g. a city name) into map coordinates, a Tool sends that text to OpenStreetMap's Nominatim service, a third-party geocoding provider. That request is subject to Nominatim's own privacy practices; see osmfoundation.org.

3. If You Request a Full Report or a Consultation

If you select a paid report, consultation, or similar option on a Tool, it opens a pre-filled JotForm in a new tab containing the birth and/or event details you already entered, plus the service option you selected. Nothing is sent anywhere until you review that form, add any additional details it asks for (such as your email address), and click Submit yourself — at that point it is sent to JotForm and made available to Sanju Paison at lifeprediction.net, so your request can be followed up on directly. Simply using a Tool to view a result does not send anything to JotForm or otherwise share your information with the developer — that only happens if you click through to a report or consultation link and submit the resulting form. Where a Tool links to a public storefront (for example, a Kindle eBook listing on Amazon) instead of a form, no personal information is sent, since it is simply a link to a public page.

4. Translation

Some Tools offer a "Translate this reading" or similar feature. Where offered and used, the text of your computed result is sent to a third-party translation service (such as MyMemory) to produce a translated version. This is only triggered if you actively choose a language other than English on a Tool that offers this feature.

5. Curated Reference Data

Some Tools compare your computed chart against a fixed, curated list of major world cities or other reference data built into the reading service. This comparison happens entirely within the reading service using data it already has, and does not involve any additional third-party service or data transmission beyond what is described in Section 1.

6. Rate Limiting

To prevent automated abuse and protect the reading service, some Tools limit the number of results a given internet connection (IP address) can request in a day. Where applied, this is tracked only as a short-lived counter tied to an IP address on a rolling 24-hour basis; it is not linked to any personal information you entered and expires automatically.

7. Third-Party Information

Any Tool on the Site may be used to generate a result based on information about someone other than you (for example, entering another person's birth date). If Section 3 applies to that request, the same handling described there applies to that person's information as well.

8. This Website

lifeprediction.net is currently hosted using GoDaddy and built on the Nicepage platform. Like most website hosting arrangements, this may involve the automatic collection of standard technical data as a normal part of serving web pages — for example, IP address, browser type, and access times — which is handled by the hosting provider rather than actively collected by the developer. The hosting provider and platform used for this website may change over time. The Tools' own code and data are additionally hosted on GitHub Pages, and their reading services run on Cloudflare Workers.

9. Analytics

This website may use one or more third-party analytics services to measure visits and engagement. These services may collect standard technical information such as IP address, device/browser type, approximate location, and pages viewed. The specific analytics provider(s) in use may change over time; current details can be requested via the contact method below.

10. What This Policy Does Not Cover

This policy covers lifeprediction.net and the Tools hosted on it only. It does not cover any third-party service you may be directed to (for example, JotForm, OpenStreetMap, MyMemory, GitHub, Cloudflare, Amazon, or a payment processor), each of which has its own separate privacy practices.

11. Changes to This Policy

This policy may be updated from time to time, including to reflect changes in hosting provider, analytics provider, the services the Tools rely on, or as new Tools are added to the Site. Continued use of the Site or any Tool on it after changes are posted constitutes acceptance of the updated policy.
